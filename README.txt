Промокотики — концепт-лаборатория

Запуск: распакуйте архив и откройте index.html в современном браузере.
Все изображения находятся в папке assets.

Что внутри:
- адаптивная галерея из 6 визуальных направлений;
- фильтры по характеру подачи;
- выбор концепции с крупным превью;
- копирование описания выбранного направления;
- карточки используют имеющиеся изображения Промокотика, новые изображения не генерировались.

Это концепт-подборка для обсуждения направления, не официальный брендбук Hoff.
